# TextMotion Studio

A small React experiment for animating text, built with Framer Motion and Tailwind CSS.

Type a sentence, choose an animation and speed, then preview the result. The controls also include color themes and optional music.

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

MP4 export is not implemented. The download button currently shows a placeholder message.

This is a front-end experiment, not a video editing tool. AI assistance was used during development.
